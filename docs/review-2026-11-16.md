# Independent reviews of the station-dependence analysis, 16 November 2026

Two referee-style reviews were run on the manuscript text and this repository (AI reviewers working independently of
the analysis, with access to the code and data; they did not change any file). Both recommended major revision. This
file records what they found and what was done, so that the results in the README can be read with that history.

## Round 1

| Issue | Response |
|---|---|
| Prior work on the elongated source not cited (Parks et al. 2025; Lanzi et al. EGU26-12710; Sigmundsson et al. IAVCEI 2025) | Cited; the elongation is stated as known |
| A line of point sources is not a pressurised cavity | Compound dislocation model ported (`scripts/cdm.py`, Nikkhoo et al. 2017, MIT) and fitted with cavity potency ratios (`scripts/cdm_source.py`) |
| East/up test biased (north neglected in the data only; depth refitted per component) | `scripts/east_up_consistent.py`: model through the same decomposition, fixed geometry; the north term changes the ratio by 0.00-0.03 |
| 2026 window and line-length selection hidden | Reported in the README caveats |
| Grindavík graben subsidence at AUSV and GEVK | Radar "virtual stations" (`scripts/implied_volume.py`) |
| Title "a single station overstates" unfair to IMO | Changed |
| Δχ² uncalibrated; GNSS inside the joint fit | Caveat added; circularity still open |
| Horizontal backgrounds mixed in 3-component fits | Vertical-only numbers used |
| Figure 2 used a different point source than Table 1 | Fixed |

## Round 2

| Issue | Response |
|---|---|
| M1: the spread shrinks because of depth and position, not shape | Confirmed (`station_volume_geometry.csv`): a point source at 3.25 km gives SENG/AUSV 1.29, the cavity 1.27. The radar accepts that depth only for an elongated body (`station_volume_geometry_radar_chi2.csv`). README reworded |
| M2: the ring has a first harmonic; the cavity reproduces a third of the second harmonic | Both harmonics fitted for data and models (`implied_volume_harmonics.csv`): a 6 km line reproduces the second harmonic (24-28 % against 16-25 %), the pressurised prolate 5-7 %; no model reproduces the WNW first harmonic |
| M3: station-scale effects at the Grindavík sites | Stated; GEVK's GNSS uplift is up to half the radar's over 3 months. Not explained |
| M4: the 2026 window does not narrow the spread | Stated in the README caveats |
| M5: "the prolate fits the radar best" was wrong | Corrected: the 6 km line fits better than the prolate in every window |
| Endpoint and lobe numbers not in CSV | `robustness_endpoints.csv`, `robustness_residual_lobe.csv`. One-sided endpoint fits change GEVK by 2.65 Mm³ (the earlier "at most 0.6" was wrong) |
| CDM port, Eshelby tensor, rotations | Checked by the reviewer line by line against Nikkhoo's MATLAB, against Mura's closed form and an independent point CDM: correct |

Still open: the WNW asymmetry (residual lobe), the cause of the GNSS/radar mismatch at GEVK, an InSAR-only geometry
for the station test, a background-trend sensitivity for AUSV and GEVK, and IMO's 2026 station set and data.
